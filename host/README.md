# Dog Tag Day Host

Portable hosting layer for Dog Tag Day. This folder is intentionally isolated from the public DogTagDay.org site.

## Purpose
- Own the control-plane code in GitHub.
- Host the iPhone control UI on Dog Tag Day's Vercel account.
- Use the existing Dog Tag Day Supabase project for queue, run history, and platform status.
- Publish directly through official Meta, TikTok, and YouTube APIs once their app credentials are attached to the host.
- Keep Commercial #1 and Commercial #2 on the three-hour America/Los_Angeles alternating schedule.
- Never mark a platform PUBLISHED without provider confirmation.
