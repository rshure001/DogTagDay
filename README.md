# Dog Tag Day Website

Official website starter for Dog Tag Day, observed every April 18.

## GitHub Pages
Upload all files and the `assets` folder to the root of the `DogTagDay` repository.

Required root files:
- index.html
- styles.css
- script.js
- README.md
- assets/official-dog-tags.png

GitHub Pages should publish from:
- Branch: main
- Folder: /(root)
