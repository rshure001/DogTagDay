# Dog Tag Day Website

This folder is ready to publish with GitHub Pages.

## Upload through the GitHub website

1. Open your **DogTagDay** repository.
2. Select **Add file** and then **Upload files**.
3. Unzip the downloaded ZIP on your device first.
4. Upload everything inside the `dog-tag-day-site` folder, including the `assets` folder.
5. Select **Commit changes**.
6. Open **Settings** → **Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then save.

Your site will normally appear at:

`https://YOUR-GITHUB-USERNAME.github.io/DogTagDay/`

## Customize

- Update the email address in `index.html` if needed.
- Replace the SVG logo files in `assets` when the final official logo is ready.
- All paths are relative, so the site works in a GitHub Pages project repository.
